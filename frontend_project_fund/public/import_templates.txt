# Import template headers (text version)

Copy these headers into the first row of each sheet when creating the Excel file manually.
Date/time columns use YYYY-MM-DD or YYYY-MM-DD HH:MM.
Foreign keys (role_id, position_id, year_id, status_id, category_id, subcategory_id, etc.) must already exist.
